% ---------- 1 ----------
\begin{taskbox}{Right now}{13:20 – 13:45}
\begin{enumerate}
  \item \textbf{Get test MON. This comes first, because it's the \#1 blocker.}
  \begin{itemize}
    \item Claim on \href{https://blitz.devnads.com}{blitz.devnads.com}, use \href{https://faucet.monad.xyz}{faucet.monad.xyz}, and ask the mentors.
    \item Send the MON to the DEPLOYER and DRIP addresses that Prompt~0 prints. The goal is at least \textbf{10 MON}.
  \end{itemize}
  \item \textbf{Check the rules with the organisers.}
  \begin{itemize}
    \item Is the submission deadline 17:30 or 17:45?
    \item Is judging really 50\,\% judges and 50\,\% the room?
    \item Which fields does the submission form on blitz.devnads.com ask for?
  \end{itemize}
\end{enumerate}
\end{taskbox}

% ---------- 2 ----------
\begin{taskbox}{Design}{13:45 – 14:30 \,·\, the part that makes the room remember you}
She makes a \textbf{short design brief} that you paste into Prompts~2 and~3. It's not Figma perfection; the brief itself says \emph{``worry less about perfect UI''}. Contents:
\begin{itemize}
  \item \textbf{Name + one-line tagline} (e.g.\ ``Live Vote: every vote is a donation'')
  \item \textbf{3 colours as hex codes plus 1 font} (from Google Fonts). The projector screen needs strong contrast and very large type.
  \item \textbf{A rough sketch of 3 screens} (paper, Figma or v0 are all fine):
  \begin{enumerate}
    \item \textbf{Phone:} the question, 3 big buttons, ``next vote costs X''
    \item \textbf{Projector:} the QR code, the bars, the counters
    \item \textbf{Winner screen:} the winning cause, the amount, the explorer link
  \end{enumerate}
  \item \textbf{All text in the app:} the question, button labels, the line ``No wallet, no app, just scan,'' and the success message after a vote
  \item \textbf{The 3–4 causes:} names plus an icon each
\end{itemize}
She can do this in the normal Claude chat, so it doesn't use up the Claude Code usage. A prompt she can use there:
\begin{promptbox}
``Create a compact design brief for a mobile voting web app called Live Vote, shown live at a hackathon on a projector. Give me: 3 hex colours, 1 Google Font, all UI text, and a layout description for 3 screens (phone voting, projector with QR code and live bars, winner screen). Keep the projector screen readable from 15 metres.''
\end{promptbox}
\end{taskbox}

% ---------- 3 ----------
\begin{taskbox}{Pitch}{14:30 – 15:00}
\begin{itemize}
  \item Write out the 3-minute pitch from PLAN.md section~6 and time it with a stopwatch.
  \item Optional: 1–2 slides (problem + roadmap). No more than that.
\end{itemize}
\end{taskbox}

% ---------- 4 ----------
\begin{taskbox}{Test users}{15:00 – 15:45}
\begin{itemize}
  \item \textbf{Recruit 5–10 people from other teams} to scan and vote at the same moment. That's the real load test.
  \item Take notes: where did people get stuck, and what was unclear? Pass it on as a short list.
\end{itemize}
\end{taskbox}

% ---------- 5 ----------
\begin{taskbox}{Backup video}{15:45 – 16:15}
\begin{itemize}
  \item \textbf{Record a full run} with the screen and a phone. On Windows, \texttt{Win + Alt + R} starts a screen recording.
  \item Save it locally and upload it to Drive as well, in case the laptop dies.
\end{itemize}
\end{taskbox}

% ---------- 6 ----------
\begin{taskbox}{Submission}{16:15 – 16:45}
\begin{itemize}
  \item Prepare the submission text: description, how it works, why Monad, and the links (provided after Prompt~6).
  \item Take 2–3 screenshots for the form.
  \item Rehearse the pitch twice, with the builder playing the audience.
\end{itemize}
\end{taskbox}

\end{itemize}
\end{taskbox}
